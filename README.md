# Roguemon

**Catch 'em all. Shoot 'em all.**

A top-down roguelike shooter built on a Pokemon-style premise. Battle through waves of enemies, pick up upgrades between fights, and stack synergy bonuses the way you would in an auto battler.

![Roguemon gameplay](https://img.itch.zone/aW1nLzEzMzAwODI4LnBuZw==/original/%2FacmpK.png)

---

## About

This game was built in two weeks for [Holistic3D Game Jam 2023](https://itch.io/jam/holistic3d-game-jam-2023). It takes the collect-and-battle structure of Pokemon and turns it into a top-down shooter, with a roguelike run structure driving upgrades and synergy bonuses between waves.

## Controls

| Action | Input |
| --- | --- |
| Move | WASD / Arrow Keys |
| Menu selections | Left Mouse Button |
